# WordCounterGo

A fast, free, SEO-optimised online word counter built with [Astro](https://astro.build).

**Features:**
- Live word, character, sentence, paragraph & reading time counting
- Text transforms: UPPERCASE, lowercase, Title Case, Sentence case, Clean spaces
- Copy to clipboard
- Dark / light mode (respects `prefers-color-scheme`, toggle in header)
- Mobile responsive
- Zero server-side processing — all runs in the browser

## Commands

| Command | Action |
| :--- | :--- |
| `npm install` | Install dependencies |
| `npm run dev` | Start dev server at `localhost:4321` |
| `npm run build` | Build production site to `./dist/` |
| `npm run preview` | Preview build locally |
